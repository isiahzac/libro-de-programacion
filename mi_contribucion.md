## Mi experiencia con Git

Durante estos ejercicios, aprendí a manejar ramas, fusionar cambios e intentar crear conflictos para después solucionarlos. 

1. Inicialicé un repositorio con Reinitialized existing Git repository in /Users/isiahzacarias/Desktop/Inkor/libro-de-programacion/.git/.
2. Creé la rama isiah-zf para realizar el ejercicio con el comando "git branch isiah-zf". Además, aprendí diferentes formas para crear ramas (git branch o git checkout) y guardar en stage la información añadida.
3. Aprendí a hacer merge con Fast-Forward y No-Fast-Forward.
4. Aunque no se generó ningún conflicto he logrado comprender un poco más el mundillo de Git.

Me pareció muy interesante entender cómo Git gestiona los cambios y, aunque aún me queda algo por aprender para tener más soltura, me siento cómodo haciendo uso de git.
